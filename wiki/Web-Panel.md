# Веб‑панель

Панель — основной человеческий интерфейс единой базы.

## Вход

Адрес: <https://api.kolodahearthstone.com/>. Доступ защищён GitHub OAuth и
allowlist. Имя активного GitHub‑аккаунта видно в верхней панели.

## Основные разделы

| Раздел | Возможности |
| --- | --- |
| Карты BG | Поиск и фильтры существ, golden variants, art lightbox |
| Герои | Отдельные hero portraits и связанная статистика |
| Коллекции | Скины, питомцы, монетки, хрономальные, Standard/Wild и BG‑механики |
| Обзор и мета | Источники, meta, архетипы, карты, колоды, Arena, BG и патчи |
| API‑токены | Выпуск, состояние и отзыв доступа |

## Работа с большими таблицами

- filters сохраняются в URL;
- поиск применяется с небольшой задержкой;
- `/` фокусирует основной поиск;
- широкая таблица имеет горизонтальную прокрутку;
- изображения lazy-loaded и открываются в lightbox;
- broken image не должен ломать строку — используется placeholder;
- кнопка **«Подробнее»** открывает все поля записи в drawer.

## Статистика

В **«Обзор и мета»** доступны отдельные модули:

- реестр всех источников;
- HSGuru meta и архетипы;
- Standard/Wild карты;
- Arena карты и общий раздел Arena;
- HSReplay архетипы и колоды;
- BG герои по mode/MMR;
- BG существа и детальные показатели;
- история патчей.

Фильтры показываются только там, где они поддерживаются источником. Не
интерпретируйте пустую таблицу как отсутствие данных до сброса format/rank/
period/mode filters.

## Состояние источников

| Метка | Значение |
| --- | --- |
| Fresh | Новый snapshot опубликован |
| Provisional | Проверенный early-patch срез |
| LKG | Используется прошлый хороший snapshot |
| Stale | Возраст выше policy |
| Failed | Нет полезной публикации |

На вкладке **«Обзор»** всегда проверяйте одновременно состояние и последнее
обновление.

## API‑токены

Создавайте один токен на один сервис. Для обычного чтения полной базы выбирайте
только `database:read`. Секрет показывается один раз; список затем показывает
только безопасные метаданные. Отзыв действует немедленно.

## Доступность

Панель поддерживает keyboard navigation, явные labels, focus в drawer/lightbox
и responsive menu. Доступны четыре визуальные темы; они не меняют данные.

Подробная инструкция: [docs/WEB_PANEL.md](../docs/WEB_PANEL.md).
