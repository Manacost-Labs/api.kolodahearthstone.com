# Руководство по веб‑панели

Веб‑панель по адресу <https://api.kolodahearthstone.com/> — рабочее место для
просмотра единой базы Hearthstone, статистики и управления API‑доступом.

## Доступ

Панель защищена GitHub OAuth. Production разрешает вход только заранее
настроенному владельцу. Если GitHub подтвердил другой аккаунт, панель должна
отказать в доступе.

После входа имя GitHub‑аккаунта отображается в верхней панели. Для завершения
сессии используйте кнопку **«Выйти»** внутри интерфейса.

## Навигация

Левое меню разделено на три рабочих области:

| Область | Что находится внутри |
| --- | --- |
| Основное | Карты BG, герои, скины, питомцы и монетки |
| Статистика | Единый раздел «Обзор и мета» |
| Операции | Состояние источников, расписание и ручные запуски парсеров |
| Доступ | Выпуск, список и отзыв API‑токенов |
| Коллекции | Хрономальные карты, Standard/Wild, аномалии, квесты, призы, награды и аксессуары |

На узком экране меню сворачивается. Кнопка **«Меню»** открывает ту же
навигацию без потери текущего раздела.

Кнопка **«Поиск»** в верхней панели или сочетание `Ctrl/⌘ K` открывает
быстрый переход. Он ищет по разделам панели, а начиная со второго символа — и
по картам текущего каталога: результат показывает миниатюру, тип и ID. Стрелки
выбирают результат, `Enter` открывает его, `Esc` закрывает окно. Карта
открывается в своём каталоге, даже если она не на первой странице.

## Каталоги

Каталоги рассчитаны на большие объёмы данных:

- поиск и фильтры сохраняются в URL, поэтому результат можно добавить в
  закладки;
- каталоги переключаются вкладками над фильтрами; у каждого фильтра есть
  подпись, активные фильтры видны отдельными метками с крестиком, а
  **«Сбросить»** очищает их разом. На телефоне фильтры спрятаны за кнопкой
  **«Фильтры · N»**, где N — число активных;
- карточка записи открывается поверх списка и добавляет в адрес
  `?card=<Card ID>`. Такую ссылку можно отправить коллеге, перезагрузка
  страницы сохраняет карточку, а «Назад» в браузере закрывает её. В карточке
  собраны название на двух языках, характеристики, текст и механики, метки
  типа, пула и форматов, Card ID и DBF с кнопками копирования, обычная и
  золотая версии, ссылки на API, статистику и редактор. Сырые поля и JSON
  находятся в блоке **«Изображения, все поля и JSON API»**. Стрелки `←` и `→`
  листают записи текущей страницы;
- вид **«Таблица»** показывает колонки своего каталога: у героев — броню,
  силу героя и напарника, у скинов — класс, персонажа и редкость, у
  Standard/Wild — класс, ману, редкость, набор и форматы, у библиотек — тир,
  группу и пул. Колонка с миниатюрой и названием остаётся на месте при
  горизонтальной прокрутке; клик по строке открывает карточку. Сортировки по
  колонкам нет: сервер отдаёт записи в своём порядке, а сортировка одной
  страницы вводила бы в заблуждение;
- изменение большинства select‑фильтров применяет их сразу;
- `/` переводит фокус в основной поиск, если курсор не находится в форме;
- таблица прокручивается горизонтально, а важное действие остаётся доступным;
- кнопка **«Компактно»** уменьшает высоту строк и запоминает предпочтение в браузере;
- меню **«Колонки»** скрывает второстепенные поля и отдельно запоминает набор
  видимых колонок для каждого каталога;
- панель **«Широкая таблица»** показывает горизонтальную позицию и позволяет
  переходить по данным кнопками влево/вправо без точного захвата scrollbar;
- изображения загружаются лениво, сломанный URL заменяется placeholder;
- нажатие на изображение открывает общий lightbox;
- обычный и золотой варианты связаны с базовой записью и доступны через поиск;
- вид **«Плитки»** подстраивает число колонок под ширину окна: одна на
  телефоне, пять при ширине 1440 px.

### Ручные правки карт Полей сражений

Импорт HearthstoneJSON перезаписывает карты при каждом запуске. Поля, которые
вы изменили в редакторе (название, тип, уровень, атака, здоровье, пул,
описание и другие), сохраняются в `battlegrounds_card_overrides` вместе со
значением источника, которое правка заменила.

- Пока источник отдаёт прежнее значение, импорт оставляет вашу правку.
- Если источник сам пришёл к вашему значению, правка больше не нужна и
  удаляется.
- Если источник изменил поле на третье значение, например после патча,
  побеждает источник. Событие `manual_released` попадает в
  `battlegrounds_card_changes`: проверьте, нужна ли правка снова.
- Ввести в поле значение источника — значит снять защиту с этого поля.

Каждое сохранение пишет в `battlegrounds_card_changes` событие `manual_edit`
с автором и списком изменённых полей. Удаление карты удаляет и её правки.

## Обзор и мета

Откройте **Статистика → Обзор и мета**. Внутри доступны модули:

| Модуль | Назначение |
| --- | --- |
| Обзор | Полный реестр источников, состояние, наличие dataset, последнее обновление и возраст |
| Мета | HSGuru Standard/Wild срезы по рангу и периоду |
| HSGuru архетипы | Архетипы и подробный анализ, включая доступные сборки |
| Standard / Wild карты | Рейтинговая статистика карт по диапазону и периоду |
| Карты Арены | Срезы карт обычной и подпольной Arena |
| Архетипы | HSReplay архетипы и связанные показатели |
| Колоды | Доступные колоды и их метаданные |
| BG герои | Герои Полей сражений по режиму и MMR bracket |
| BG существа | Существа, уровни таверны и детальные раунды/метрики |
| Арена | Общая Arena‑статистика и источники |
| Патчи | Версии игры и связанные изменения |

Набор фильтров зависит от модуля. Например, мета использует формат, ранг и
период, BG — режим и рейтинговый диапазон, Arena — режим/источник.

### Подробная запись

У каждой строки статистики есть действие **«Подробнее»**. Оно открывает
keyboard‑accessible drawer со всеми scalar и nested полями, которые вернул
источник. Это важно для архетипов, колод, BG‑существ и других записей, где
короткой таблицы недостаточно.

Raw JSON доступен для проверки интеграции, но пользовательский интерфейс
показывает нормализованные названия и значения там, где это возможно.

### Как читать состояние источника

| Состояние | Интерпретация |
| --- | --- |
| Fresh / `ok` | Последний refresh прошёл проверки |
| Provisional | Ограниченный, но проверенный post-patch срез |
| LKG / `ok_cached` | Новый refresh не принят; показывается предыдущий хороший набор |
| Stale | Срез старше допустимой freshness policy |
| Failed | Полезный набор пока недоступен |

Зелёный liveness API не означает, что каждый источник свежий. На **Обзоре**
оценивайте источник по состоянию и времени обновления.

## Парсеры

Откройте **Операции → Парсеры**. Верхняя строка показывает только сигналы,
требующие решения: активный запуск, число стабильных источников, проблемы и
ближайшее расписание.

Таблица источников поддерживает поиск, фильтр состояния, разделы и компактную
плотность. Через **«Колонки»** можно оставить только нужные операционные поля.
Стрелки над таблицей помогают быстро перейти к расписанию и действиям справа.
Первая колонка и действие запуска закреплены, поэтому источник не
теряется при горизонтальной прокрутке. Для каждого источника видны:

- рабочее состояние и последняя безопасная ошибка;
- число опубликованных строк и канал публикации;
- последний успешный сбор;
- расписание и следующий запуск;
- доступность ручного запуска.

Кнопка **«Запустить»** открывает подтверждение с причиной. Запрос проходит через
закрытый same-origin bridge, GitHub session и CSRF-проверку; admin token никогда
не передаётся JavaScript. Повторяющийся запуск дедуплицируется API, а действия
владельца фиксируются в audit log.

Раздел **«Последние запуски»** обновляется автоматически. Он показывает статус,
прогресс по источникам, инициатора, время и безопасные сообщения ошибок без
секретов.

## Управление API‑токенами

Откройте **Доступ → API‑токены**.

### Выпуск

1. Введите имя одного конкретного потребителя.
2. Выберите минимальные scopes.
3. Укажите срок действия.
4. Нажмите **«Выпустить токен»**.
5. Скопируйте появившийся секрет в secret manager.

Секрет больше не будет показан. В таблице останутся только id, имя, scopes,
срок, последнее использование и статус. Столбец «Использование» показывает
запросы и ошибки за текущий месяц из `usage.request_count` и
`usage.error_count`. Для длинного реестра доступны тот же
компактный режим, выбор колонок и горизонтальная навигация, что в каталогах.

### Выбор прав

| Потребитель | Рекомендуемые права |
| --- | --- |
| Сайт/бот читает полную базу | `database:read` |
| Служебный процесс запускает refresh | `admin` |
| Отдельный manager выпускает токены | `tokens:manage` |

Не выдавайте `admin` или `tokens:manage` обычному frontend‑клиенту.

### Отзыв

Найдите токен и нажмите действие отзыва. Доступ прекращается сразу. Токен
самой панели нельзя отозвать из панели, чтобы случайно не потерять управление.

Полная модель: [API_TOKENS.md](API_TOKENS.md).

## Темы и доступность

В меню **«Разделы»** доступны темы **Как в системе**, **Светлая**,
**Тёмная**, **Таверна** и **Аркана**. «Как в системе» следует настройке
светлого или тёмного режима устройства и меняется вместе с ней. Выбор
сохраняется в браузере и синхронизируется между вкладками. Выбранная тема не
меняет структуру данных. Текст на заливных
кнопках берёт цвет из `--on-accent` и `--on-bad` своей темы; контраст не ниже
4.5:1 проверяет `panel-next/tests/theme-contrast.test.ts`.

Даты показываются по-русски: время запусков — относительно («5 минут назад»,
«через 42 минуты»), точное время в UTC — во всплывающей подсказке. Состояния
источников и записей подписаны словами и окрашены: зелёный — в норме, жёлтый —
резерв или внимание, красный — ошибка или нет данных, синий — выполняется.

Ключевые действия доступны с клавиатуры; lightbox, drawer и мобильное меню
имеют явные labels и состояние focus. Если таблица шире экрана, используйте её
горизонтальную область прокрутки.

## Если данные не появились

1. Откройте **Парсеры** и проверьте состояние соответствующего источника.
2. Обновите конкретный модуль кнопкой **«Обновить»**.
3. Сбросьте поиск и специальные фильтры.
4. Проверьте вкладку **«Обзор»**: есть ли dataset и когда он обновлён.
5. Если источник LKG/stale/failed, это проблема обновления данных, а не
   браузерного отображения.
6. Если весь экран пуст, проверьте HTTP status и browser console, затем
   используйте [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
