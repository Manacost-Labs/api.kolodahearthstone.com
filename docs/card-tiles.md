# Адаптивные плитки для приложений

REST `/api/v1` возвращает два способа показать плитку:

- `tile_image_url` / `images.tile`: прежняя готовая PNG 640×128.
- `tile_layout`: слои и параметры для адаптивного компонента приложения.

`tile_layout.version = 1`. Размеры и шрифты заданы для высоты **64**.
Выберите любую ширину от 200 и любую высоту; умножьте все размеры на
`height / 64`. Ширина названия вычисляется из фактической ширины контейнера.
Полный текст всегда находится в `title.text`; сервер его не сокращает.

| Слой | Как показать |
| --- | --- |
| `background` | Залить цветом; при наличии `gradient` использовать stops с позициями 0…1. Угол соответствует CSS: 0° вверх, 90° вправо. |
| `art` | Картинка высотой контейнера и шириной `height × aspect_ratio`. Прижать справа с отступом `end_inset × scale`. Обрезать выход за границы плитки. Не растягивать по ширине. `url = null` означает отсутствие арта. |
| `cost` | Левая колонка `column_width × scale`. Значок и текст расположить по центру. |
| `title` | Один ряд текста между `inset_start × scale` и правым отступом `inset_end × scale`; переполнение сокращать многоточием. |
| `badge` | Правая непрозрачная колонка цвета `background.color`, шириной `column_width × scale`. Если есть `icon`, показать его вместо `text`. |

Все текстовые слои выравниваются по вертикальному центру. Углы и выход арта
обрезаются по `corner_radius`. Примените `text_style` для обводки и тени;
`cost.outline_color` заменяет общий цвет обводки для стоимости.

`font_url` содержит публичную TTF. Загрузите игровые шрифты один раз и
кэшируйте их вместе с кристаллом маны и звездой. Арт, шрифты и значки доступны
с CORS. У легендарных карт используется отдельный PNG значка: игровой шрифт
не содержит символ звезды.

В Standard/Wild стоимость показывается в кристалле маны, цвет зависит от
редкости. В Battlegrounds слева уровень таверны, справа цена покупки:
3 для существ, фактическая стоимость для заклинаний. Цвет существ зависит
от расы; заклинания сохраняют нейтральный фон. `—` означает неизвестное число,
а 0 сохраняется как настоящая стоимость.

Рабочий пример с изменением ширины: `panel/examples/adaptive-deck-tile.html`.
Переиспользуемый DOM-компонент: `panel/examples/adaptive-deck-tile.js`.
Чтобы открыть пример, запустите `python3 -m http.server 4183 --directory panel/examples`
и перейдите на `http://127.0.0.1:4183/adaptive-deck-tile.html`.

## Кэш API

Публичный `/api/v1` имеет серверный кэш 30 секунд с блокировкой заполнения
одинакового ключа и обновлением в фоне. Разные URL/query-параметры и методы
GET/HEAD имеют отдельные ключи. Авторизация, сессия панели и запросы с
`Cache-Control: no-cache` / `no-store` / `max-age=0` обходят кэш. Ошибки,
ответы с Set-Cookie и явным private/no-store/no-cache не сохраняются.
Состояние видно в `X-API-Cache`: MISS, HIT, BYPASS, STALE или UPDATING.

Условные запросы поддерживают ETag; If-None-Match имеет приоритет над
If-Modified-Since. Last-Modified учитывает изменения кода и файлов плиток.
При изменении API-контракта нужно обновить API_VERSION и версию в ключе
`fastcgi_cache_key`, чтобы старый ответ не оставался в серверном кэше.

Ссылки на PNG берутся из маленьких атомарных индексов отдельных карт.
Общий manifest сохранён для совместимости и восстановления. Индексы
обновляет `panel/scripts/sync_card_tiles.py` после синхронизации арта.
